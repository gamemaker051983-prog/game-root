# 🎮 CARNAGE MMORPG - Объединенная игра

Полноценная браузерная MMORPG игра, объединяющая интерфейс и игровую механику в единое приложение.

## 🚀 Быстрый запуск

### Вариант 1: Десктопная кнопка (Рекомендуется)
1. Дважды кликните на файл `CARNAGE-GAME.bat`
2. Игра автоматически откроется в браузере
3. Наслаждайтесь игрой!

### Вариант 2: Ручной запуск
1. Откройте командную строку в папке проекта
2. Выполните команду: `node simple-server.js`
3. Откройте браузер и перейдите на `http://localhost:3000`

## 🛠️ Технические детали

### Архитектура
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Node.js, Express.js
- **Стили**: Кастомный CSS с анимациями
- **Шрифты**: Google Fonts (Cinzel для заголовков)

## 🔧 Настройка и кастомизация

### Изменение настроек
- **Порт сервера**: Измените `PORT` в `simple-server.js`
- **Цвета**: Отредактируйте CSS переменные в `carnage-game.html`
- **Локации**: Добавьте новые локации в JavaScript код
- **Персонажи**: Настройте характеристики в объекте `character`

### Добавление функций
- **Новые локации**: Расширьте массив локаций
- **Дополнительные предметы**: Добавьте в инвентарь
- **Новые противники**: Создайте в боевой системе
- **Социальные функции**: Расширьте чат и друзей
